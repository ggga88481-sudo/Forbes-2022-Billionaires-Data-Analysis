# Forbes World's Billionaires List 2022 — Data Analysis

## 📊 Project Overview

This project is a practical Data Analysis project using Python and the Forbes World's Billionaires List 2022 dataset.

The project focuses on exploring, cleaning, analyzing, and visualizing data about billionaires from around the world.

## 🛠️ Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## 🔍 Project Includes

* Data exploration
* Data cleaning
* Handling missing values
* Data analysis
* Data visualization
* Extracting insights from the dataset

## 📁 Files

* `python for data analysis project.ipynb` — The complete analysis notebook.
* `Forbes-2022-Billionaires-db.csv` — The dataset used in the project.
